# A MAZE

**Pitch:** A short 2.5D isometric dungeon race: you and your rivals drop into the same hidden dungeon, and whoever reaches the golden star in the centre first wins. There's no minimap and no arrow, so you explore, read your rivals' fading footprints and mess with them using funny weapons and traps.

- **Genre:** Isometric dungeon racing / party arcade (roguelite run of floors)
- **Engine:** Unity 6 (URP)
- **Platforms:** Web (WebGL), Windows, Android (iOS project planned)
- **Orientation:** Portrait
- **Public play URL:** none yet. The web build is meant for the `Raseosan/a-maze-play` repo (https://github.com/Raseosan/a-maze-play), but GitHub Pages isn't enabled on it, so https://raseosan.github.io/a-maze-play/ returns 404.

## Features
- Fog of view and no map: you only see a few tiles around you, and every generated maze is checked so each spawn has the same shortest route to the star.
- Five chibi racers built in code, with slapstick hits, dizzy stars, pickups (Confusion horn and more) and hidden traps.
- Runs of 20 to 45 second floors against 5 computer racers that only know what they can see. Finish in the top spots to advance and pick a perk.
